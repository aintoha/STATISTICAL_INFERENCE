1.1 Random Variables

  • When analysing the result of an experiment, it is easier to deal with the function of the possible outcomes rather than the outcome itself

  • For example, in an experiment of tossing a coin twice and observing the number of Heads, the possible outcomes are: TT, TH, HT, HH

    The function is SUM of Heads which are 0, 1, and 2.

  • These are quantitiesa are Random Variable

Definition 1.1 (Random Variable) Given a random experiment with an outcome space \(S\), a function \(X\) that assigns one and only one real number \(X(s) = x\) to each element \(s\) in \(S\) is called a random variable.

The space of \(X\) is the set of real numbers \(\{x: X(s) = x, s \in S\}\), where \(s \in S\) means that the element \(s\) belongs to the set \(S\).

  • A random variable, usually written \(X\), is a variable whose possible values are numerical outcomes of a random phenomenon.

  • A random variable assigns a numerical value to each outcome in a sample space.

  • Looking it in mathematical function

  1. Domain: TT, HT, TH, HH

  2. Function, \(X\): The rule you define (i.e. The number of Head)

  3. Space of \(X\), Range: 0, 1, 2

Example 1.1 A rat is selected at random from a cage and its sex is determined.

  • The set of possible outcomes is female and male.

  • The outcome space is \(S = \{\text{female}, \text{male}\} = \{F, M\}\).

  • Let \(X\) be a function defined on \(S\) such that \(X(F)= 0\) and \(X(M)=1\).

  • \(X\) is then a real-valued function that has the outcome space \(S\) as its domain and the set of real numbers \(\{x: x= 0, 1\}\) as its range.

  • We call \(X\) a random variable and the space associated with \(X\) is \(\{x: x=0, 1\}\).

  • It may be possible that the set \(S\) has elements that are themselves real numbers.

-In such an instance, we could write \(X(s) = s\) so that \(X\) is the identity function, and the space of \(X\) is also \(S\).

Example 1.2 The experiment is tossing a die. Then the outcome space associated with this experiment is \(S= \{1, 2, 3, 4, 5, 6\}\) with elements of \(S\) indicating the number of spots on the side facing up.

  • For each \(s \in S\), let \(X(s) = s\).

  • The space of the random variable \(X\) is then \(\{1, 2, 3, 4, 5, 6\}\).

1.2 RV and Distribution Function

Random variable can be divided into

  • Discrete

  • Continuous

1.3 Discrete Random Variable

It is a random variable (RV) that can take on at most countable number of possible values.

Probability distribution for a discrete random variable:

  • can be represented by a formula, a table, or a graph, which provides \(P(X) = P(X=x)\) for all \(x\).

  • It assigns nonzero probabilities to only a countable number of distinct \(x\) values.

  • Any value \(x\) not explicitly assigned a positive probability is understood to be such that \(P(X=x) = 0\).

  • The function \(f(x) = p(x) = P(X=x)\) for each \(x\) within the range of \(X\) is called the probability distribution of \(X\).

  • It is often called the probability mass function (p.m.f) for the discrete random variable \(X\).

  • For the p.m.f, \(f(x)\) is positive for at most a countable number of values of \(x\) and satisfies the following properties:

    1. \(f(x_i) \ge 0, x \in S\)

    2. \(\sum_{x \in S} f(x_i) = 1\)

    3. \(P(x \in A) = \sum_{x \in A} P(x), A \subset S\)

1.4 Continuous Random Variable

\(X\) is a continuous RV if there exists a nonnegative function \(f(x)\) defined for all real \(x \in (-\infty, \infty)\), having the property that for any set \(B\) of real numbers, \(P(X \in B) = \int_B f(x)dx\).

Probability distribution for a continuous random variable: \(f(x)\) is approximately equal to the relative frequency of the interval \(\{x: a < x < b\}\) and hence can be thought of as an estimate of the probability that the RV \(X\) falls into the interval \((a, b)\). This probability is often written as \(P(a < x < b) = \int_{a}^{b} f(x)dx\). It is often called the probability density function (pdf) for the continuous random variable \(X\).

1.4.1 Properties of continuous Random Variable

The p.d.f. \(f(x)\) satisfies:

  • \(f(x) > 0\) for \(x \in S\) .

  • \(\int_{-\infty}^{\infty} f(x) dx = 1\) .

  • \(P(a < x < b) = \int_a^b f(x) dx\) .

  • Note: If \(a=b\), then \(P(x=a) = \int_a^a f(x) dx = 0\).

If \(a, b \subseteq S\), then the probability of the event \(\{a < x < b\}\) is \(P(a < x < b) = \int_{a}^{b} f(x)dx\).

Remarks: if \(a=b\), then \(P(x=a) = \int_{a}^{a} f(x)dx = 0\).

Example 1.5 Suppose that \(X\) is a continuous random variable whose probability density function is given by:

\[\begin{align} f(x) = \begin{cases} C(4x - 2x^2) & 0 < x < 2 \\ 0 & \text{otherwise} \end{cases} \end{align}\]

  1. What is the value of \(C\)?

  2. Find \(P(X>1)\).

Solution:

  1. Since \(f\) is a probability density function, we must have

\[\int_{-\infty}^{\infty} f(x)dx = 1\]

\[\begin{align} C \int_{0}^{2} (4x - 2x^2)dx =& 1 \\ C \left[2x^2 - \frac{2x^3}{3} \right]_0^2 =& 1 \\ C =& \frac{3}{8} \end{align}\]

  1. Hence, \(P(X>1) = \frac{3}{8} \int_{1}^{2} (4x - 2x^2)dx = \frac{1}{2}\).

1.4.2 Cumulative Distributive Function (CDF)

Definition 1.2 (Cumulative Distributive Function (CDF)) The cumulative distribution function or CDF of a RV \(X\), denoted by \(F(x)\) is defined by \[F(x) = P(X \le x), \text{ for all } x.\] \[F(x) = \begin{cases} \sum_{X \le x} P(x) & \text{discrete R.V} \\ \int_{-\infty}^{x} f(t)dt & \text{continuous R.V} \end{cases}\]

Example 1.6 Consider the table below:

\(x\) \(1\) \(2\) \(3\) \(4\)
\(P(x)\) \(1/4\) \(1/2\) \(1/8\) \(1/8\)

\[F(x) = \begin{cases} 0 & x < 1 \\ 1/4 & 1 \le x < 2 \\ 3/4 & 2 \le x < 3 \\ 7/8 & 3 \le x < 4 \\ 1 & 4 \le x \end{cases}\]

Example 1.7 Let \(X\) has the p.d.f of \(f(x) = \begin{cases} 0 & -\infty < x < 0 \\ \frac{1}{20}e^{-x/20} & 0 \le x < \infty \end{cases}\)

To obtain C.D.F, \[F(x) = \int_{-\infty}^{x} f(t)dt = \int_{0}^{x} \frac{1}{20} e^{-t/20} dt = \left[ -e^{-t/20} \right]_0^x = 1 - e^{-x/20}\] Also, \(F'(x) = f(x)\).

1.4.3 Relationship between CDF, \(F(x)\) and p.m.f or p.d.f

\(F(x) \rightarrow\) p.m.f , p.d.f

  • If discrete, \(P(x = a) = F(a) - F(a^-)\)

  • If continuous, \(f(x) = \frac{dF(x)}{dx} = F'(x)\)

p.m.f, p.d.f \(\rightarrow F(x)\)

  • If discrete, \(F(x) = \sum P(x)\)

  • If continuous, \(F(x) = \int_{-\infty}^{x} f(x)dx\)

1.4.4 Properties of CDF

\(F(x)\) is CDF if and only if the following 3 conditions hold:

  1. \(\lim_{x \to -\infty} F(x) = 0\) and \(\lim_{x \to \infty} F(x) = 1\)

  2. \(F(x)\) is non decreasing function of \(x\)

  3. \(F(x)\) is right continuous

Example 1.8 A batch of 15 items contains 6 defective ones. A random sample of 5 is chosen. Let \(X\) be the number of defective items in the sample. Find the probability function and cumulative distribution function for \(X\).

Example 1.9 Let \(X \in \mathbb{R}\) with PDF as

\[\begin{align} f(x) = \begin{cases} 0 & -\infty < x < 0 \\ \frac{1}{20} \exp \left(-\frac{x}{20}\right) & 0 \le < \infty \end{cases} \end{align}\]

Derive the CDF of \(X\).

Solution \[\begin{align} F(x) &= \int_{-\infty}^{0} f(t) \ dt \\ &= \int_{0}^{x} \frac{1}{20} \exp \left(-\frac{x}{20}\right) \ dt \\ &= \left[-\frac{x}{20}\right]_{0}^{x} = 1 - \exp \left(-\frac{x}{2-}\right) \end{align}\]

Check: the derivative of \(F(x)\) must equal to \(f(x)\)

1.5 Random Walk for Discrete Random Variable

The mathematical concept of the “drunken walk” - formally known as the random walk—was developed independently at the turn of the 20th century by thinkers across finance, biology, and physics attempting to model unpredictable behavior.

1.5.1 Application of Random Walk

  • Drawing a random card from the deck is mathematically identical to clicking the “Take Step” button. Both trigger a single, independent 50/50 random event that dictates the next move.

  • The Red Card vs. The Green Upward Line

    • Drawing a Red Card to gain $10 is the same as a positive market event.

    • On the simulator’s Tree Preview, this is represented by the green line moving diagonally upward, increasing the asset’s value by whatever number you typed into the “Volatility Step” box.

  • The Black Card vs. The Red Downward Line

    • Drawing a Black Card to lose $10 translates to a negative market shock.

    • On the visual tree, this is the red line moving diagonally downward to a lower price node.

  • The 4 Draws vs. The Number of Weeks

    • Playing a game with 4 card draws is identical to setting the simulator’s “Number of Weeks” to 4.

    • Each vertical column of circles on the grid represents the exact state of the market after one draw.

1.6 Expected Values and Expected Function

It is a value that were expected to emerge when performing some random experiment. So basically, it is average or mean of the outcomes.

Definition 1.3 (Expected Values and Expected Function) The expected value or mean of a random variable \(X\), denoted by \(E(X)\) is: \[\mu = E(X) = \begin{cases} \int_{-\infty}^{\infty} x f(x)dx & \text{if } X \text{ is continuous} \\ \sum x f(x) = \sum g(x)P(X=x) & \text{if } X \text{ is discrete} \end{cases}\]

Example 1.10 (Example 8) Let \(X\) equal number of spots on the side facing upwards after a six-sided die (one of pair of dice) is cast at random. If everything is fair about this experiment, a reasonable probability model is given by the p.m.f. \(f(x) = P(X=x) = 1/6\), where \(x=1,2,3,4,5,6\). Therefore, the expected value of this distribution is: \[\mu = E(X) = \sum_{x=1}^{6} x\left(\frac{1}{6}\right) = 1\left(\frac{1}{6}\right) + 2\left(\frac{1}{6}\right) + 3\left(\frac{1}{6}\right) + 4\left(\frac{1}{6}\right) + 5\left(\frac{1}{6}\right) + 6\left(\frac{1}{6}\right) = \frac{7}{2}\]

From previous Example 8, Let \(Y=X^2\), then \(Y\) is also a random variable such that p.m.f of \(Y\) is \(g(y) = P(Y=y) = 1/6\), where \(y=1,4,9,16,25,36\). Suppose we wanted to find the expected value of \(Y\), \(E(Y)\), and \(Y=X^2\), then we can also compute: \[E(Y) = E(X^2) = \sum_{x=1}^{6} x^2 f(x) = \frac{1^2}{6} + \frac{2^2}{6} + \frac{3^2}{6} + \frac{4^2}{6} + \frac{5^2}{6} + \frac{6^2}{6} = \frac{91}{6}\] Note that, \(E(X^2)\) also known as second moment about the origin with respect to variable \(X\).

1.6.1 Variance and standard deviation

Calculation for Variance and standard deviation can also be calculated using expectation. Where: \[Var(X) = E[(X-\mu)^2] = E(X^2) - \mu^2\] \[\sigma = \sqrt{Var(X)}\]

Example 1.11 (Example 9) Let the p.m.f. of \(X\) be defined by \(f(x) = x/6\), where \(x = 1, 2, 3\). The mean of \(X\) is \(\mu = E(X) = 1(1/6) + 2(2/6) + 3(3/6) = 14/6 = 7/3\). Find the variance and standard deviation of \(X\).

Example 1.12 (Example 10) Find \(E(X)\), \(Var(X)\) and Standard deviation of \(X\) when the density function of \(X\) is \(f(x) = 2x\) if \(0 \le x \le 1\), and \(0\) if \(x\) is otherwise.

1.6.2 Expectation of function

  • If \(X\) is a discrete RV, with \(x_i, i \ge 1\) with probabilities \(p(x_i)\), then \(E[g(X)] = \sum_i g(x_i)p(x_i)\).
  • Let \(X\) be a random variable with density \(f(x)\). The expected value of a function \(g(\cdot)\) of the random variable, denoted \(E(g(X))\), is defined to be \(E(g(X)) = \int_{-\infty}^{\infty} g(x)f(x)dx\).

1.6.3 Expectation Properties

  • \(E(x+c) = E(x) + c\)

  • \(E(c) = c\)

  • \(E(x+y) = E(x) + E(y)\)

  • \(E(ax) = aE(x)\)

  • \(|E(x)| \le E(|x|)\)

Let \(X\) be a RV and \(a, b\) and \(c\) are constants. Then, for any functions \(g_1(x)\) and \(g_2(x)\) whose expectations exist:

  1. \(E(ag_1(x) + bg_2(x) + c) = aEg_1(x) + bEg_2(x) + c\)

  2. If \(g_1(x) \ge 0\) for all \(x\), then \(Eg_1(x) \ge 0\)

  3. If \(g_1(x) \ge g_2(x)\) for all \(x\), then \(Eg_1(x) \ge Eg_2(x)\)

  4. If \(a \le g_1(x) \le b\) for all \(x\), then \(a \le Eg_1(x) \le b\)

1.7 Moments and Moment generating function

Definition 1.4 (Methods of Moments) The moments of RV or of a distributions are the expectations of the powers of the RV which has the given distributions. If \(X\) is a RV, the \(r\)th moment of \(x\) is defined as \(\mu_r' = E[X^r]\). Therefore, the \(r\)th moment about the origin of a random variable is the expected value of \(X^r\): \[\mu_r' = E(X^r) = \begin{cases} \sum_x x^r f(x) \\ \int_{-\infty}^{\infty} x^r f(x)dx \end{cases}\]

The first moment is \(E(X)\).

Definition 1.5 (Centrol Moments) The \(r\)th moment about the mean of a random variable \(X\), is the expected value of \((X - \mu_X)^r\), symbolically, \[\mu_r = E[(X - \mu_X)^r] = \begin{cases} \sum_x (x - \mu_X)^r f(x) \\ \int_{-\infty}^{\infty} (x - \mu_X)^r f(x)dx \end{cases}\]

The \(r\)th moment about the mean of a random variable \(X\) is sometimes called the \(r\)th central moment of \(X\). Note that: * \(\mu_1 = E[(X - \mu_X)] = 0\) * \(\mu_2 = E[(X - \mu_X)^2] = Var[X]\) Variance can be also written as \(\sigma_X^2 = \mu_2' - \mu_X^2\).

The first moment is mean of \(E(X)\). The second central moment is the variance. If \(E(X^n)\) exists for some +ve integers \(n\), we call \(E(X^n)\) the \(n\)th moment of \(X\) about the origin. If \(E|X^n| < \infty\) for some +ve real number \(\alpha\), we call \(E|X^n|\) the \(\alpha\)th absolute moment of \(X\).

Definition 1.6 (Moment Generating Function (MGF)) Moment generating function \(M(t)\) of the RV \(X\) is defined for all real values of \(t\) by: \[M(t) = E[e^{tx}] = \begin{cases} \sum e^{tx} p(x) & \text{if } X \text{ is discrete} \\ \int_{-\infty}^{\infty} e^{tx} \cdot f(x)dx & \text{if } X \text{ is continuous} \end{cases}\]

Example 1.13 (Example 11 (Discrete case)) Let the p.m.f. of \(X\) be defined by \(f(x) = x/6\), where \(x=1,2,3\). Find the mgf of RV of \(X\).

1.7.1 Finding probability distribution from mgf

Sometimes we can find the probability distribution of the random variable from observing their mgf. Since mgf is unique to each RV if the mgf exists. For discrete case; let space of \(S\) is \(\{b_1, b_2, b_3, \dots\}\), then the moment-generating function is given by the expansion: \[M_X(t) = e^{tb_1}f(b_1) + e^{tb_2}f(b_2) + e^{tb_3}f(b_3) + \dots\] Thus, the coefficient of \(e^{tb_i}\) is the probability of \(f(b_i) = P(X=b_i)\).

For continuous case; it is not as easy as the discrete case since it does not involve with expansion. But since mgf is unique to one random variable, we can see that in later topic, it is easy to find the pdf of given mgf.

1.7.2 Properties of mgf

\[M'(t) = \frac{d}{dt}E[e^{tx}] = E\left[ \frac{d}{dt}(e^{tx}) \right] = E[Xe^{tx}]\] \[M'(0) = E(x)\] \[M''(t) = \frac{d}{dt}M'(t) = \frac{d}{dt}E[Xe^{tx}] = E\left[ \frac{d}{dt}(Xe^{tx}) \right] = E[X^2e^{tx}]\] \[M''(0) = E(X^2)\]

  1. If \(M_X(t)\) exists, then for any positive integer \(k\), \(\frac{d^k M_X(t)}{dt^k} \Big|_{t=0} = M_X^{(k)}(0) = E(X^k)\), i.e. we can find the \(k\)th mgf through the \(k\)th derivative of with respect to \(t\) by setting \(t=0\) (discrete case). We call \(M_X(t)\) the mgf because all the moments of \(X\) can be obtained by differentiating \(M_X(t)\) and then evaluating the result at \(t=0\).

Example 1.15 (Example 11 (Cntinuous case)) using the same problem in example 11, find mean and variance of \(X\) using the mgf.

If \(X\) has mgf, then \(E(X^k) = \frac{d^k M_X(t)}{dt^k} \Big|_{t=0} = M_X^{(k)}(0)\), i.e. the \(n\)th moment of the distribution is equal to the \(n\)th derivative evaluated at \(t=0\) (continuous case).

For independent variable \(X\) and \(Y\); \(M_{X+Y}(t) = M_X(t) \cdot M_Y(t)\) and for any constant \(a,b \in \mathbb{R}\): * \(M_{X+a}(t) = E(e^{(X+a)t}) = e^{at} \cdot M_X(t)\) * \(M_{bX}(t) = E(e^{bXt}) = M_X(bt)\) * \(M_{\frac{X+a}{b}}(t) = E\left(e^{\frac{X+a}{b}t}\right) = e^{\frac{a}{b}t} M_X\left(\frac{t}{b}\right)\)
