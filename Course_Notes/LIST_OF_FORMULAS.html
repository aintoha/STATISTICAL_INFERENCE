Fundamental Probability Concepts

Concept Formula Notes
1. Independent Probability \(P(A \cap B) = P(A) \cdot P(B)\) Equivalent to \(P(A \mid B) = P(A)\) when \(P(B) > 0\).
2. Conditional Probability \(P(A \mid B) = \dfrac{P(A \cap B)}{P(B)}\) Defined for \(P(B) > 0\).
3. Bayes’ Rule \(P(A_i \mid B) = \dfrac{P(B \mid A_i)P(A_i)}{\sum_{j=1}^{k} P(B \mid A_j)P(A_j)}\) Partition \(\{A_1, A_2, \dots, A_k\}\) where \(P(B) > 0\).
4. Discrete Probability Mean: \(\mu = E[X] = \sum x \, p(x)\)
Variance: \(\sigma^2 = \text{Var}(X) = \sum (x - \mu)^2 p(x) = E[X^2] - (E[X])^2\)		 \(p(x) = P(X = x)\).
5. Continuous Probability Mean: \(\mu = E[X] = \int_{-\infty}^{\infty} x \, f(x) \, dx\)
Variance: \(\sigma^2 = \text{Var}(X) = \int_{-\infty}^{\infty} (x - \mu)^2 f(x) \, dx = E[X^2] - (E[X])^2\)		 \(f(x)\) is the Probability Density Function (PDF).

Negative Binomial \((r, p)\) (trials to \(r\) successes) \(\binom{x - 1}{r - 1} p^r (1 - p)^{x - r}\) \(\sum_{k=r}^{\lfloor x \rfloor} \binom{k-1}{r-1} p^r (1-p)^{k-r}\) \(x \in \{r, r+1, r+2, \dots\}\) \(\dfrac{r}{p}\) \(\dfrac{r(1 - p)}{p^2}\)
Hypergeometric \((N, K, n)\) \(\dfrac{\binom{K}{x} \binom{N - K}{n - x}}{\binom{N}{n}}\) \(\sum_{k=0}^{\lfloor x \rfloor} \dfrac{\binom{K}{k} \binom{N - K}{n - k}}{\binom{N}{n}}\) \(\max(0, n - (N - K)) \le x \le \min(n, K)\) \(n \dfrac{K}{N}\) \(n \dfrac{K}{N} \left(1 - \dfrac{K}{N}\right) \left(\dfrac{N - n}{N - 1}\right)\)
Poisson \((\lambda)\) \(\dfrac{\lambda^x e^{-\lambda}}{x!}\) \(\sum_{k=0}^{\lfloor x \rfloor} \dfrac{\lambda^k e^{-\lambda}}{k!} = \dfrac{\Gamma(\lfloor x \rfloor + 1, \lambda)}{\lfloor x \rfloor!}\) \(x \in \{0, 1, 2, \dots\}\) \(\lambda\) \(\lambda\)
